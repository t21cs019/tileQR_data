# 不老・弐 DTSMQR 1コア計測の解析（2026-11-11）

## 1. 結論

- **不老・弐（EPYC 9965）の β = 124、A = 99.7 GFlops**（ib = nb/8、size 4096、5回の平均、MRE 2.6%）。回ごとの β は 122.5〜124.9 で、計測の再現性は高い。ただし手続きへの感度が大きい（MaxIB では β = 68、nb の範囲を変えると 101〜150）。
- **この A・β を使った当てはめなしのモデルは、不老・弐の QR（p = 192）に合わない。** 予測の最適 nb は 32〜128、実測は 176〜400。予測の nb での性能は実測の最大の 2〜3%（size 8192 だけ 24%）。
- 実測/予測（= η_eff/η理論）は nb 32 の 0.001 から nb 512 の 0.73〜0.95 まで上がり続ける。「小さい nb で落ちる」傾向は EPYC 7543 よりはるかに強い。β の不確かさ（68〜150）や A のクロック補正では説明できない大きさ。

## 2. データの確認

- **条件は指示書どおり。** 5 本とも host t1205、plasma-bench ee9701b、`CORE=1 NODE=0 SIZE=4096 STEP=4 NB=32-512 N_IT=50`、`numactl --physcpubind=1 --membind=0`、PBS 112117.jobm。NoFlush の ldd は自前の OpenBLAS（`~/Library/openblas`）。5 本とも 3963 行で、格子と順は期待どおり。NaN なし。
- **回ごとのばらつきは小さい。** 点ごとの (最大 − 最小)/中央値は、中央 0.5%、90% 点 1.3%、99% 点 3.6%。当てはめに使う点（断面 113 点）では最大 2.8%。回の順の傾向はない（回ごとの平均の差は ±0.07% 以内）。外れた回はない。
- **外れた点は当てはめに入らない。** 最初の点（nb 32, ib 8）は 5 回とも 0.05〜4.2 GFlops（隣の ib 12 は約 14）で、起動直後のため使えない。5% を超えてばらつく点は 21 点（11 点は nb < 64、残りは ib = 8 か 16）。単発の落ち込みは (nb 52, ib 24, r1) −94% と (nb 372, ib 8, r5) −45%。ib = 8（各 nb の最初の点）はばらつきが大きめで（中央 1.4%、ほかは 0.5%）、断面の nb 64〜76 はこの ib = 8 を使う。
- **クロック**：回ごとの中央値は 3755〜3756 MHz。3740 MHz を下回る記録は 2 つ（r2 の 01:31:55 に 1800.0、r4 の 02:23:01 に 3702.0）。r2 のその時刻の前後（nb 416〜432）の値に落ち込みはない（中央値との差の平均 −0.06%）。
- **再現する段差（ノイズではない）**：nb = 512 はどの ib でも、5 回とも低い（ib 64 で 71.0、nb 508 は 79.5）。断面は ib の丸め（4 刻み）で階段になる（例：nb 112 で ib 12 は 41.6、ib 16 は 51.2）。
- **指示書と違っていた点**：`raw/ssrfb/t1205/` に同じ 5 回がすでに取り込まれていて（未コミット）、`beta_from_ssrfb()` は flow2-t1 の β = 123.83 を返す。下の値と一致する。こちらでは何も変更していない。

## 3. β と A（DTSMQR、1コア、size 4096、nb 64〜512 の 113 点）

| 機種 | 手続き | 5回の平均：β / A / MRE | 回ごとの範囲：β / A / MRE |
|---|---|---|---|
| 不老・弐 EPYC 9965 | **ib = nb/8** | **123.8 / 99.7 / 2.6%** | 122.5〜124.9 / 99.3〜100.0 / 2.55〜2.60% |
| 不老・弐 EPYC 9965 | MaxIB | 67.7 / 95.0 / 1.5% | 67.1〜68.7 / 94.9〜95.3 / 1.48〜1.61% |
| EPYC 7543（size 4096、7月） | ib = nb/8 | 342.7 / 69.4 / **11.5%** | 341.3〜343.6 / 69.2〜69.4 / 11.5% |
| EPYC 7543（size 4096、7月） | MaxIB | 189.5 / 63.0 / 4.8% | 189.0〜191.2 / 63.0〜63.3 / 4.8〜4.9% |
| EPYC 7543（これまでの値） | ib = nb/8 | 184.3 / 60.1 / 2.0〜2.1% | size 1024・2048・8192（8月）の 3 本の平均 |

- **EPYC 7543 の size 4096（7月の r1〜r5）は MRE 11.5% で、これまでの手続きでは除かれる曲線。** 階段が ±20〜30% ある（`fig_kernel_fit.png` の右）。同じ手続きで並べられる EPYC 7543 の値は、ほかの 3 つの size から決めた β = 184.3、A = 60.1。
- **不老・弐と EPYC 7543 の違い**：β は 0.67 倍（124 と 184）、A は 1.66 倍（99.7 と 60.1）。原因は推定で、世代の違い（Zen 5c と Zen 3 の SIMD の幅やキャッシュ）と考えられるが、確かめていない。
- **A は外挿した値**（実測の最大は断面で 80.6 GFlops、全格子で 83.6 GFlops。どちらも nb 504）。**手続きへの感度**（不老・弐、5回の平均）：
  - MaxIB にすると β は 124 → 68（45% 減）。MaxIB が選ぶ ib は nb の約 1/3 で、nb/8 より大きい。断面は MaxIB より 7〜19% 低い。
  - nb の範囲：nb 64〜256 で β = 150、nb 96〜512 で 117、nb 128〜512 で 101。残差に系統的な形がある（nb 64〜127 で −2%、128〜191 で +3%）。E の形が曲線に完全には合っていない。nb = 512 を除くと β = 125.3（ほぼ変わらない）。
- **8 の倍数のギザギザ**：MaxIB の曲線には出ている（8 の倍数の nb は両隣の平均より +0.7〜+1.6%、それ以外は −1.1%）。断面でははっきりしない（ib の丸めによる階段のほうが大きい。ib ごとの残差の平均は −4.5〜+5.2%）。当てはめへの影響：8 の倍数だけで β = 119、それ以外だけで 129（断面）。MaxIB では 63 と 73。
- **size は 4096 の1つだけ。** 他の機種では size による β の違いは小さい（EPYC 7702：182〜189）が、不老・弐では確かめていない。

## 4. QR との比較（p = 192、c = √7.5、k = 2、A = 99.7、β = 123.8。クロックの補正なし）

QR の実測は `add_baseline` の base（速い水準）を (nb, ib) ごとに GFlops に直し、ib について最大を取った曲線。
実測/予測は η_eff/η理論 と同じもの。

| size | 予測の最適 nb | 実測の最適 nb（最大から 5% 以内の範囲） | 予測の nb での実測 / 実測の最大 | 実測の最適 nb での 実測/予測 |
|---|---|---|---|---|
| 1024 | 32 | 176（176〜176） | 0.03 | 0.32 |
| 2048 | 40 | 208（172〜212） | 0.02 | 0.44 |
| 4096 | 72 | 220（212〜224） | 0.03 | 0.41 |
| 8192 | 128 | 400（280〜456） | 0.24 | 0.62 |

| size（実測/予測、base） | nb 64 | 128 | 192 | 256 | 384 | 512 |
|---|---|---|---|---|---|---|
| 1024 | 0.03 | 0.17 | 0.35 | 0.49 | 0.80 | 0.95 |
| 2048 | 0.01 | 0.18 | 0.38 | 0.54 | 0.77 | 0.85 |
| 4096 | 0.01 | 0.09 | 0.34 | 0.46 | 0.73 | 0.81 |
| 8192 | 0.01 | 0.07 | 0.23 | 0.35 | 0.58 | 0.73 |

- **比は nb とともに上がり続け、nb 512 でも頭打ちにならない**（`fig_qr_ratio.png`）。モデルが合うなら比は nb によらず一定のはず。
- **5回の平均でも、MaxIB の A・β でも結論は同じ。** 5回の平均：実測の最適 nb は 184 / 188 / 212 / 408、予測の nb での性能比は 0.02 / 0.01 / 0.03 / 0.20（比の値は base より低く、nb 448 で 0.68〜0.76）。MaxIB（A = 95.0、β = 67.7）：予測の最適 nb は 32 / 36 / 64 / 104 で、実測からさらに離れる。
- **「小さい nb で落ちる」傾向**：不老・弐でも出ていて、EPYC 7543 より強い。nb 64 での比は不老・弐 0.01〜0.03、EPYC 7543 は 0.37〜0.66（`2026-10-27_gen4-kernel-term/data/eta_eff.csv`、size 1024〜16384）。nb 128 では 0.07〜0.18 と 0.50〜0.85。
- **クロックの補正：不明、補正していない。** QR の `_meta.txt` にあるのは、計測の前後の「全 384 CPU の平均」（size 4096 r1 で 2997 と 2970 MHz）だけ。使っていないソケットを含み、計測中の値でもない。なお、補正は A を一律に下げるだけなので、比の nb 依存と予測の最適 nb は変わらない。

## 5. ゼミで言ってよい表現と、言ってはいけない表現

言ってよい
- 「不老・弐の DTSMQR を1コアで計測し、これまでと同じ手続きで β = 124、A = 99.7 GFlops を得た。5 回の β は 122.5〜124.9」
- 「この β・A を入れた当てはめなしのモデルは、p = 192 の QR に合わない。予測の最適 nb（32〜128）は実測（176〜400）より小さく、実測/予測は小さい nb ほど低い」
- 「EPYC 7543 で見えた小さい nb での落ち込みが、192 コアではずっと大きい」
- 「β は手続きで変わる（MaxIB で 68、nb の範囲で 101〜150）。size は 4096 だけ」

言ってはいけない
- 「不老・弐の β は 124 と決まった」（感度が大きく、size も1つ）
- 「A = 99.7 GFlops が1コアの実測の性能」（外挿。実測の最大は 80.6〜83.6）
- 「ずれの原因はタスクの起動の時間／クロックの低下」「192 コアでのクロックは ○ GHz」（今回は確かめていない。クロックは記録がない）
- 「EPYC 7543 の size 4096 と同じ条件で比べた」（その曲線は MRE 11.5% で除かれる。比べたのは 3 つの size の平均）

## 6. 次に確かめること

1. **（計測なし）2026-11-10 の「タスク数 × τ」の式を、今回の A・β で不老・弐の QR に当てる。** 実測/予測の nb 依存が τ の1項で説明できるか、size によらない τ になるかを見る。
2. **（研究室の EPYC 7543、無償）size 4096 の DTSMQR を取り直す。** 7月の r1〜r5 は階段が大きく手続きから除かれるので、同じ size での比較ができていない。
3. **（ゼミで相談する案、有償）不老・弐の DTSMQR を size 1024 と 8192 で各1回**：β が size によらないかの確認。ノード時間は約 25 分 × 2 = 約 50 分（今回の実績。5 回の β の幅が ±1% なので1回で足りる）。あわせて、次に 192 コアの QR を流す機会があれば、計測中のクロックを記録する（追加のノード時間は不要）。

再現：`scripts/` で `python -I a_check.py`、`b_fit.py`、`c_qr.py` の順（`c_qr.py` は `data/b_fits.csv` を読む）。
