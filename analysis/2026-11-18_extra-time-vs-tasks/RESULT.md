- **g（定義をそろえた）**：不老・弐も定義M（実測 − T_model）で出した。不老・弐の nb < 予測 nb の傾きは **1.02**（R² 0.90、n = 20、余分な時間 ≤ 0 は 0 点）、nb ≥ 予測 nb は 0.50、全点 0.58。定義K（E_並列 を引かない）では 1.02 / 0.37 / 0.46。3機種の nb ≥ 予測 nb の傾きは M → K で 0.37 → 0.23（7543）、0.58 → 0.32（7702）、0.67 → 0.24（Xeon）。どの機種も、定義を変えても nb ≥ 予測 nb で 1 には戻らない（M のほうが高い）。
- **h（比例する nb の範囲）**：1タスクあたりの余分な時間が小さい nb 側の中央値から ±30% を外れ始める nb は、4機種・19 組の size で **56〜136**（最大/最小 2.4 倍）。予測 nb との比は 0.19〜2.4、N は 16〜171、余分/実測は 0.02〜0.98 とずっと広く散るので、範囲を決めているのは **nb そのもの（合う）**。予測 nb・N・余分の割合では合わない。なぜ nb 56〜136 かは分からない。
- **i（c0 + τ·タスク数）**：size ごとの c0 + τ·タスク数（全 nb）で、nb ≥ 予測 nb の傾きの低下の 104〜121% を再現した（4機種、定義M）。式の形としては **c0 で傾きの低下を説明できる**。ただし c0 は行列の大きさ（size²）に比例せず（3機種は c0 ∝ size^1.6〜2.4、負の切片や負の c0 もある）、不老・弐だけ 6.7 ms ＋ 0.157 ms/MB の直線で 7 ms 以内に乗る。h で比例とされた範囲だけの当てはめは、外側を予測できない（c0 が負になる）。
- **j（原因の候補）**：この定義とこのデータでは、傾きの低下を最もよく説明したのは候補1（c0 の形：size 共通の a0 + b·MB でも 4機種で 109〜125%（Xeon は b < 0 で意味が通らない）。計算時間に比例する項 a·t_ideal の形は 6〜35%）。ノイズ・ならし（候補2）は 0〜4%、並列度の不足（候補3、不老・弐）は約 10%、格子の端・size 1024 の除外（候補4）は −35〜+16%（Xeon は点が少なく不安定）。c0 の中身は分からない。
- **l（当てはめ線の誤差）**：i 節の c0 + τ·タスク数 の全点の当てはめ（余分な時間 ≤ 0 の点も含む、重み 1/t_obs）の、全体の時間の相対誤差 RMS は、小さい nb で EPYC 7543 8.8%・7702 7.6%・Xeon 4214 6.4%（大きい nb の 1.1 / 0.6 / 0.7 倍）で**小さい nb で大きくは外れない**。**不老・弐だけ 54%（偏り −53%、3.1 倍）で大きく外れる**（点は 20 点）。小さい nb だけで当てはめた τ は、3機種では全点の τ とほぼ同じ（0.64〜1.25 倍）、不老・弐で 2.1〜3.6 倍。「小さい nb では τ が大きく、1 つの τ では全域は合わない」は不老・弐でだけ数字で言える。
