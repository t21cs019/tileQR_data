# 2026-11-10 Brent の下限と上限で nb の探索範囲を絞り、Optuna を再現する

10-28 のミーティングの指摘「Brent の定理の下限も使えないか」への試算。未コミット。
考察（何が分かったか、注意点、残っていること）は vault にある：`tileQR_research/chats/2026-11-10_brent-lower-bound.md`。
ここには、そのノートの数値を出したスクリプト・表と、再現手順を置く。
新しい計測はしていない。計測済みのスイープ（nb × ib、各5回）を引いて Optuna を再現した。

- データ：HT 無効・1ソケットの13構成・57条件。QR の曲線と A_k・β_k は `analysis/2026-10-27_gen4-kernel-term/data/eta_eff.csv`、(nb, ib) ごとの5回の値は `derived/qr_sweep.parquet`
- Optuna は 4.5.0（一時環境）。tileQR_data の `.venv` には入っていない

## 探索範囲の作り方

```
y = p·D/W（W = 4N³、D = 30N − 28、N = size/nb）
時間の上限 = (W/p)(1 + y)        時間の下限 = (W/p)·max(1, y)        W/p は p·A_k·E_k(nb) で時間に直す
B     : 下限の時間 ≤ 上限の時間の最小、となる nb（当てはめの定数なし）
B_tau : 同じ条件で、両方に タスク数·a·p（a = 0.092 µs）を足す
thr92 : 参考。上限＋τ の予測性能が、最大の 92% 以上の nb
full  : 計測した全範囲（32〜512）
```

| 範囲 | 実測の最適 nb を含む | 範囲内の最高 ÷ 全体の最高（最低） | 残す nb の割合（平均） |
|---|---|---|---|
| B | 56 / 57（外れは EPYC 7702 の size 1024） | 98.8% | 53% |
| B_tau | 57 / 57 | 100% | 52% |
| thr92 | 57 / 57 | 100% | 39% |

## Optuna の再現の設定

- 既定の TPE。nb と ib を同時に探す。1回 100 試行、乱数の種 0〜19 の 20 回
- ib は 8 〜 nb/2（計測した格子の全部）。卒論は「2 から nb の半分までの偶数」で、ib 2〜6 は計測していないので入らない。nb も卒論は 4〜512 だが、計測は 32〜512
- 目的関数は2通り。`single` は5回の計測値から1つを無作為に引く。`mean5` は5回の平均を返す（卒論と同じ。1試行で QR を5回実行したことにする）
- 到達度 ＝ Optuna がその時点で最良と見ている (nb, ib) の5回平均 ÷ 全 (nb, ib) の5回平均の最大

- 1試行の実行時間は、mean5 が single の5倍

## 前半の試算（下限を予測式・診断・探索範囲に使えるか）

- **予測式を下限に置き換えると悪くなる**（`data/eta_forms_summary.csv`）。η を (1 + y^q)^(1/q) で上限（q = 1）から下限（q = ∞）まで変えると、予測 nb での性能比は τ なしで平均 95.6% → 89.9%、τ = a·p あり（LOAO）で 97.6% → 90.2%。下限は nb を 2^0.45 = 1.37 倍に大きく予測する
- **実測は上限の時間の線に近く、多コアではそれより遅い**（`data/eta_position.csv`）。p ≥ 24 は 970 点すべてが上限の時間より遅い側（実測 ÷ 上限の線は中央値 0.58〜0.68）。p ≤ 12 の y = 0.3〜3 は中央値 1.01〜1.04。A_k の絶対水準（r0 = 0.71〜1.18）に依存する
- **範囲の作り方は B がよい**（`data/range_two_ways.csv`）。A（2つの予測 nb の間）は最適を含むのが 34 / 57、範囲内の最高は最低 76.0%。B は 56 / 57、最低 98.8%。参考の2ソケット・SMT 有効の26条件では B でも 18 / 26（AOBA-B の2ソケットは最低 74.5%）
- **B の広さは、しきい値 0.85 と同じくらい**（`data/range_variants.csv`）。57条件のうち35条件は、範囲の上端が計測格子の端の 512

## 注意

- 最初に 50 試行・1回の値だけで流した実験は、同じ乱数の種の 100 試行（`single`）の前半と同じなので、別には残していない
- 実機ではなく、計測済みの表を引く再現。ib 2〜6 と nb 4〜28 は計測がないので探せない
- 範囲の式は τ の定数 a = 0.092 µs を全57条件の当てはめから取っている（B_tau と thr92）。B は当てはめの定数を使わない
- 「下限と上限の間に必ず入る」は仮定の上の話。実測の η は上限の線より遅い側にあることが多く（p ≥ 24 は全点）、57条件で成り立ったという経験的な結果
